# Loan Eligibility Prediction

Machine Learning project that predicts whether a loan application is eligible based on applicant and loan-related information.

## Technologies

- Python
- Pandas

- NumPy
- Scikit-learn
- Matplotlib
- Machine Learning
- SVM
- Decision Tree
- Artificial Neural Network (MLPClassifier)

## Models

- Decision Tree
- Support Vector Machine (SVM)
- Multilayer Perceptron (ANN)

## Dataset

The project uses applicant information such as income, education, credit history, property area, loan amount and other features.

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Data Preprocessing
4. Feature Encoding
5. Feature Scaling
6. Train/Test Split
7. Model Training
8. Model Evaluation
9. Prediction
